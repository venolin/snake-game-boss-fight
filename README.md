# Snake Game with Boss Fight

This is a test application created to demonstrate AI coding capabilities. The project includes a fully functional snake game with an added boss fight feature.

## Features

- Classic snake gameplay with smooth controls
- Boss fight triggered at 100 points
- Boss movement AI that tracks the snake head
- Health system for boss combat
- Win condition when boss is defeated
- Responsive design and visual feedback

## How to Play

1. Use arrow keys or WASD to control the snake
2. Eat food to grow and increase your score
3. Avoid hitting walls or yourself
4. Reach 100 points to trigger the boss fight
5. Defeat the boss by hitting it with your snake head
